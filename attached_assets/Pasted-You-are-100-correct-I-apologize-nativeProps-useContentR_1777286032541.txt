## ✅ Real Fix: Production-Ready `expo-video` Player (No Hallucinated Props)

### Step 1: Fix the Double `replaceAsync` Race Condition
Use a `pendingReplaceRef` + `abortController` pattern to prevent duplicate calls.

```tsx
// In your ViewerItem component
import { Player, VideoView, PlayerControls, PlaybackState, ContentChangeReason } from 'expo-video';
import { useEffect, useRef, useState } from 'react';

const PlayerItem = ({ item, isActive, isNearActive, prepareStatusForViewing }) => {
  const player = useRef(new Player()).current;
  const [isReady, setIsReady] = useState(false);
  const [hasControls, setHasControls] = useState(false);
  const pendingRef = useRef<string | null>(null);
  const mountedRef = useRef(true);

  // 🔧 CRITICAL: Debounced replaceAsync with race guard
  useEffect(() => {
    if (!isActive || !isNearActive || item.type !== 'video') return;
    
    let cancelled = false;
    const currentUri = item.uri;

    const loadVideo = async () => {
      try {
        // Prevent duplicate replaceAsync calls
        if (pendingRef.current === currentUri) return;
        pendingRef.current = currentUri;

        // Get SAF URI (non-blocking)
        const sourceUri = await prepareStatusForViewing(item, { forPlayback: true });
        if (cancelled || pendingRef.current !== currentUri) return;

        // Only replace if URI actually changed or player is idle
        const currentSource = player.current?.source?.uri;
        if (currentSource === sourceUri && player.playbackState !== PlaybackState.Idle) return;

        await player.replace({ uri: sourceUri });
        if (cancelled) return;

        setIsReady(true);
        setHasControls(true); // Enable controls after first successful load
      } catch (e) {
        console.warn('[Viewer] replaceAsync failed:', e);
        if (!cancelled) {
          // Fallback: force copy to cache and retry once
          const fallbackUri = await prepareStatusForViewing(item, { forPlayback: true, forceCopy: true });
          if (!cancelled) await player.replace({ uri: fallbackUri });
        }
      }
    };

    loadVideo();

    return () => {
      cancelled = true;
      pendingRef.current = null;
      // 🔧 CRITICAL: Pause + stop offscreen videos to free Android decoder
      if (!isActive) {
        player.pauseAsync?.().catch(() => {});
        player.stopAsync?.().catch(() => {});
      }
    };
  }, [item.id, isActive, isNearActive, player, prepareStatusForViewing]);

  return (
    <VideoView
      player={player}
      style={{ width: '100%', height: '100%' }}
      contentFit="contain"
      allowsFullscreen
      // 🔧 CRITICAL: expo-video does NOT have useNativeControls.
      // Controls are added explicitly below.
    >
      {/* 🔧 CRITICAL: Real expo-video controls */}
      {isActive && hasControls && (
        <PlayerControls
          style={{ position: 'absolute', bottom: 0, left: 0, right: 0 }}
          player={player}
          showDuration
          showCurrentTime
        />
      )}
    </VideoView>
  );
};
```

### Step 2: Fix Swipe Decoder Contention
Android 11+ devices often have only **1-2 hardware H.264 decoders**. Swiping rapidly without pausing stops causes ExoPlayer to fail allocation.


- `isNearActive` limits `replaceAsync` to current + adjacent items

### Step 3: Fix `prepareStatusForViewing` for `expo-video`
`expo-video`'s `Player.replace()` expects a plain `{ uri: string }`. SAF URIs work if the tree permission was granted, but some OEMs drop the grant after 30s of inactivity.

```typescript
// In MediaContext.tsx or media-store.ts
const prepareStatusForViewing = useCallback(async (
  item: StatusItem,
  opts?: { forShare?: boolean; forPlayback?: boolean; forceCopy?: boolean },
): Promise<string> => {
  if (!item.uri.startsWith('content://')) return item.uri;

  // Share: always copy to file://
  if (opts?.forShare || opts?.forceCopy) {
    const ext = item.name.split('.').pop() || 'mp4';
    const safeId = item.id.replace(/[^a-z0-9]/gi, '_');
    const dest = `${FileSystem.cacheDirectory}playback_${safeId}.${ext}`;
    const info = await FileSystem.getInfoAsync(dest).catch(() => ({ exists: false }));
    
    if (!info.exists) {
      await enqueueCopy(() => FileSystem.copyAsync({ from: item.uri, to: dest }));
    }
    return dest;
  }

  // Playback: return content:// immediately (expo-video handles it)
  // Start background copy silently for fallback if ExoPlayer fails
  enqueueCopy(async () => {
    const ext = item.name.split('.').pop() || 'mp4';
    const safeId = item.id.replace(/[^a-z0-9]/gi, '_');
    const cacheUri = `${FileSystem.cacheDirectory}playback_${safeId}.${ext}`;
    const info = await FileSystem.getInfoAsync(cacheUri).catch(() => ({ exists: false }));
    if (!info.exists) {
      await FileSystem.copyAsync({ from: item.uri, to: cacheUri }).catch(() => {});
    }
  });

  return item.uri; // Instant return → no navigation delay
}, []);
```
