## 🎯 Critical Issue #1: VideoView Missing Android SAF Flags

**Your Current Code (`viewer.tsx` ~line 780):**
```tsx
<VideoView
  key={item.id}
  player={player}
  style={StyleSheet.absoluteFill}
  contentFit="contain"
  nativeControls={true}  // ✅ Good
/>
```

**The Problem:** 
- `expo-video`'s `VideoView` uses ExoPlayer under the hood
- ExoPlayer on Android 11+ **requires explicit URI permission** for `content://` SAF URIs
- Without `grantUriPermission`, ExoPlayer fails silently → thumbnail stays, controls never appear

**✅ Fix: Add Android-specific native props**
```tsx
<VideoView
  key={item.id}
  player={player}
  style={StyleSheet.absoluteFill}
  contentFit="contain"
  nativeControls={true}
  // 🔧 CRITICAL: Android SAF compatibility flags
  {...(Platform.OS === 'android' && {
    // Tell ExoPlayer to use ContentResolver for content:// URIs
    nativeProps: {
      useContentResolver: true,
      grantUriPermission: true,
    },
    // Prevent network fallback attempts
    isNetwork: false,
  })}
/>
```

## 🎯 Critical Issue #2: replaceAsync Race Condition

**Your Current Flow:**
```tsx

      player.replaceAsync(mediaUri).then(() => {
        // ... readyToPlay handling
      });

  });

```

**The Problem:**
- `replaceAsync` called 100ms after interactions
- But `VideoView` only mounts when `isActive` is true
- If `isActive` flips during that 100ms window → `replaceAsync` targets unmounted player → silent failure

**✅ Fix: Only call replaceAsync when VideoView is definitely mounted**
```tsx
// In ViewerItem useEffect
useEffect(() => {
  // Only prepare video when this slot is ACTIVE (VideoView is mounted)
  if (item.type !== 'video' || !isActive || !player) return;
  
  let cancelled = false;
  
  const prepareVideo = async () => {
    try {
      // 🔧 CRITICAL: Pass forPlayback to trigger SAF accessibility check
      const preparedUri = await prepareStatusForViewing(item, { forPlayback: true });
      
      if (cancelled) return;
      
      // Only call replaceAsync when player is definitely ready
      await player.replaceAsync(preparedUri);
      
      // Start watchdog timer for fallback copy if needed
      watchdogTimerRef.current = setTimeout(() => {
        if (!isReadyToPlayRef.current && preparedUri === item.uri) {
          // Force copy fallback
          prepareStatusForViewing(item, { forPlayback: true, forceCopy: true })
            .then(fallbackUri => {
              if (!cancelled) player.replaceAsync(fallbackUri);
            });
        }
      }, 2500); // 2.5s watchdog
    } catch (e) {
      console.error('[Viewer] Video prepare failed:', e);
      if (!cancelled) setVideoError('Failed to load');
    }
  };
  
  prepareVideo();
  
  return () => {
    cancelled = true;
    if (watchdogTimerRef.current) clearTimeout(watchdogTimerRef.current);
    // Unload player to free hardware decoder
    player.unloadAsync?.().catch(() => {});
  };
}, [item, isActive, player, prepareStatusForViewing]);
```

## 🎯 Critical Issue #3: Back Button Not Intercepted

**Your Current Code:** No hardware back handler in `ViewerScreen`.

**The Problem:**
- Android hardware back sends event to activity
- React Navigation's `router.back()` may not be ready if JS thread is blocked
- Gesture detector may eat the first few taps while re-showing controls

**✅ Fix: Add BackHandler + useFocusEffect**
```tsx
// In ViewerScreen component
import { BackHandler } from 'react-native';
import { useFocusEffect } from '@react-navigation/native';

useFocusEffect(
  useCallback(() => {
    const onBackPress = () => {
      // Unload any active video players to free decoders
      if (flatListRef.current) {
        const items = flatListRef.current?.getListRef()?.getScrollableNode?.();
        // Optional: iterate and unload players
      }
      router.back();
      return true; // Prevent default back behavior
    };

    const subscription = BackHandler.addEventListener('hardwareBackPress', onBackPress);
    return () => subscription.remove();
  }, [])
);
```

## 🎯 Critical Issue #5: prepareStatusForViewing Blocking Navigation

**Your Current Code in `MediaContext.tsx`:**
```tsx
const prepareStatusForViewing = useCallback(async (item, opts) => {
  if (!item.uri.startsWith('content://')) return item.uri;
  
  if (!opts?.forShare) {
    // Returns URI immediately ✅ Good
    return item.uri;
  }
  // ... share copy logic
}, []);
```

**The Problem:** 
- Returns SAF URI immediately → good for navigation speed
- But ExoPlayer may fail to play it without explicit permission
- No fallback mechanism if direct playback fails

**✅ Fix: Add background copy fallback + accessibility check**
```tsx
const prepareStatusForViewing = useCallback(async (
  item: StatusItem,
  opts?: { forShare?: boolean; forPlayback?: boolean; forceCopy?: boolean },
): Promise<string> => {
  if (!item.uri.startsWith('content://')) return item.uri;
  
  // Share path: always copy (share sheet needs file://)
  if (opts?.forShare) {
    const ext = item.name.split('.').pop() || 'jpg';
    const safeId = item.id.replace(/[^a-z0-9]/gi, '_');
    const tempUri = `${FileSystem.cacheDirectory}share_${safeId}.${ext}`;
    
    const info = await FileSystem.getInfoAsync(tempUri).catch(() => ({ exists: false }));
    if (info.exists) return tempUri;
    
    return enqueueCopy(() => FileSystem.copyAsync({ from: item.uri, to: tempUri }));
  }
  
  // Playback path: return URI immediately + start background copy for fallback
  if (opts?.forPlayback) {
    // Start background copy silently (for fallback if direct playback fails)
    if (!opts.forceCopy) {
      enqueueCopy(async () => {
        const ext = item.name.split('.').pop() || 'mp4';
        const safeId = item.id.replace(/[^a-z0-9]/gi, '_');
        const cacheUri = `${FileSystem.cacheDirectory}playback_${safeId}.${ext}`;
        
        const info = await FileSystem.getInfoAsync(cacheUri).catch(() => ({ exists: false }));
        if (!info.exists) {
          await FileSystem.copyAsync({ from: item.uri, to: cacheUri }).catch(() => {});
        }
      });
    }
    
    logDirectPlaySuccess();
    return item.uri; // Return immediately → no navigation delay
  }
  
  // Default: return URI
  return item.uri;
}, []);
```
