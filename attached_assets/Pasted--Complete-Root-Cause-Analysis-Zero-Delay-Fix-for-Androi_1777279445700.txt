🎯 Complete Root Cause Analysis & Zero-Delay Fix for Android 11+ Images
You're experiencing delay on tap, black screens on swipe, and sluggish response because Android 11+ forces every image access through the SAF ContentResolver IPC bridge, and your current viewer decodes full-resolution bitmaps synchronously on mount. Here's exactly why it happens and the production-ready architecture to fix it permanently.

Black screen on swipe
Next image isn't loaded. Swiping mounts a new <Image> that starts decoding from scratch. Black screen = time between mount and decode completion.

Stutter/Jank
Full-res bitmaps allocate 8-15MB each. Rapid swipes trigger Android ART Garbage Collector. GC pauses block JS thread → UI freezes.

SAF Amplification
content:// URIs require cross-process IPC. First access has no cached FileDescriptor. Glide/Coil must re-open stream per decode.
50-120ms IPC overhead
Bottom Line: The slowness isn't React Native. It's unoptimized decoding + zero preloading + SAF IPC latency. Fix the pipeline, and it becomes instant.
🚀 Complete Fix Architecture (4 Pillars)
Pre-Navigation Prefetch: Start decoding the target image before router.push completes.
Zero-Black-Screen Placeholder: Render a cached thumbnail instantly, crossfade to decoded full-res image.
Aggressive Downscaling + Cache: Decode at screen size, not original resolution. Reuse bitmaps via recyclingKey.
Background Swipe Preloading: Decode currentIndex ± 1 while user views current image.
