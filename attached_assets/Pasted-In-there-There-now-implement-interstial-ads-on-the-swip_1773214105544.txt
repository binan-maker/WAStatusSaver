The goal is:

* No personal data
* No login
* Just verify **install source**

Here is the **clean architecture**.

---

# 1️⃣ What Data You Actually Need to Collect

Only collect **4 small things**.

### 1. Referral Code

Unique code generated when the app installs.

Example:

```
referralCode: K8D4F2
```

This identifies **the inviter device**, not the person.

---

### 2. Install Referrer

When someone installs through a link.

Example:

```
referrerCode: K8D4F2
```

This tells you **who invited them**.

You get this using:

* Google Play Install Referrer API

---

### 3. Device Install ID

A random ID generated when the app first runs.

Example:

```
installId: d91a3f7c-39b2
```

This prevents **multiple fake installs**.

You can generate with:

```
UUID v4
```

No personal data involved.

---

### 4. Reward Expiry

When ad-free ends.

Example:

```
adFreeUntil: 2026-04-15
```

Stored locally.

---

# 2️⃣ Minimal Database Structure

Even the smallest backend works.

Example:

```
referrals
   installId
      referralCode
      invitedBy
      timestamp
```

Example record:

```
installId: 72s92h
referralCode: 72s92h
invitedBy: K8D4F2
timestamp: 2026-03-10
```

### Step 1

User shares link:

https://yourapp.com/install?ref=K8D4F2
```

### Step 2

Friend installs from Play Store.

The system detects:

```
referrerCode = K8D4F2
```

### Step 3

New app install generates:

```
installId = 82HF3
```

---

### Step 4

Server records:

```
82HF3 invitedBy K8D4F2

---

### Step 5

Reward inviter.

```
adFreeUntil + 30 days
```

# 4️⃣ What You DO NOT Need to Collect

You do **not need**:

❌ Name
❌ Phone number
❌ Email
❌ Account
❌ Location

This keeps the system **privacy safe**.

---

# 5️⃣ Tools That Make This Easy

Recommended stack:

* Google Play Install Referrer API → detect who invited
* Firebase Cloud Firestore → store referrals
* Expo → generate install ID locally

Cost: **free for small apps**.

# 6️⃣ Anti-Cheat Protection

To prevent fake invites:

Allow reward only if:

```
different installId
different device
first app launch
```

Also limit:

```
max 5 invites per day
```
