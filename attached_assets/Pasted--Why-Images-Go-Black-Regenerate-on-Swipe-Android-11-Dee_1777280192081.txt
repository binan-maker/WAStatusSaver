🖼️ Why Images Go Black & Regenerate on Swipe (Android 11+ Deep Dive)
🔍 The Exact Technical Reason
When you swipe, React Native unmounts the off-screen <Image> component. This triggers:
expo-image releases the decoded bitmap from memory
Android's ContentResolver drops the FileDescriptor for that content:// URI
When you swipe back, the component remounts → opens a new SAF IPC stream → decodes from scratch
During decode, the view renders black until the bitmap is ready
This is not a bug. It's React Native's default view recycling + Android 11+ SAF stream lifecycle. Gallery apps don't experience this because they use view pooling, persistent native bitmaps, and aggressive memory caching.

We'll implement a 4-layer pipeline that eliminates unmounting, forces memory retention, pre-decodes off-screen slides, and overlays a transparent placeholder to hide the ~30ms SAF stream open time.
