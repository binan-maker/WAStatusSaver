# 🚨 Critical Issue: `ExpoMediaLibrary.getAlbumAsync` Permission Rejected + App Blinking on Android 11+

Based on your logs and repository analysis, here are the **exact root causes** and **production-ready fixes** for the permission error and UI blinking.

## 🔍 Root Cause Analysis

### ❌ Problem #1: Android 11+ Permission Model Mismatch

**The Error:**
```
[Error: Call to function 'ExpoMediaLibrary.getAlbumAsync' has been rejected.
→ Caused by: Missing MEDIA_LIBRARY permissions.]
```

**Why This Happens on Android 11+:**

| Android Version | Required Permission | Your App's Declaration |
|----------------|-------------------|----------------------|
| **Android 10 and below** | `READ_EXTERNAL_STORAGE` | ✅ Likely declared |
| **Android 11-12** | `READ_EXTERNAL_STORAGE` + `MANAGE_EXTERNAL_STORAGE` (optional) | ❌ Missing SAF fallback |
| **Android 13+** | `READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO` | ❌ Not declared in `app.json` |

**`expo-media-library` requires version-specific permissions**, and if any are missing, `getAlbumAsync` throws immediately.

### ❌ Problem #2: Permission Check Happens AFTER `getAlbumAsync` Call

**Current Flow in `rescanGalleryAlbum`:**
```typescript
async function rescanGalleryAlbum(currentValid: SavedItem[]) {
```

**Result:**

- State updates rapidly: `isLoading: true` → `isLoading: false` → empty state → data loads
- **UI blinks** between these states on every mount

### ❌ Problem #4: Rapid State Updates Cause UI Blinking

When `rescanGalleryAlbum` fails:
```
1. Component mounts → isLoading: true → shows shimmer
2. loadSavedItems runs → rescanGalleryAlbum throws → returns early
3. isLoading: false → shows EmptyState or cached data
4. User sees "flash" between loading → empty → loaded
5. On Android 11+, SAF delays amplify this flicker
```

### ✅ Step 2: Fix `rescanGalleryAlbum` with Permission Guard

Replace the function in `contexts/MediaContext.tsx` or `lib/media-store.ts`:

```typescript
// 🔧 SAFE: Check permissions BEFORE calling getAlbumAsync
async function rescanGalleryAlbum(currentValid: SavedItem[]): Promise<SavedItem[] | null> {
  try {
    // 🔧 CRITICAL: Check permission status first
    const { status } = await MediaLibrary.getPermissionsAsync();
    
    // Android 13+ requires specific media permissions
    const hasMediaPermission = 
      status === 'granted' || 
      Platform.OS !== 'android' || 
      (Platform.Version as number) < 33; // Android 13 = API 33
    
    if (!hasMediaPermission) {
      console.log('[MediaLibrary] Permission not granted, skipping album rescan');
      return null;
    }
    
    const album = await MediaLibrary.getAlbumAsync('StatusVault');
    if (!album) return null;
    
    const valid = [...currentValid];
    const knownUris = new Set(valid.map(v => v.localUri));
    const knownNames = new Set(valid.map(v => v.name));
    
    let after: string | undefined;
    let pageGuard = 0;
    let added = false;
    
    while (pageGuard < 20) {
      pageGuard += 1;
      const page = await MediaLibrary.getAssetsAsync({
        album: album.id,
        mediaType: ['photo', 'video'],
        first: 100,
        ...(after ? { after } : {}),
        sortBy: [[MediaLibrary.SortBy.creationTime, false]],
      });
      
      for (const asset of page.assets) {
        if (knownUris.has(asset.uri) || knownNames.has(asset.filename)) continue;
        const isVideo = asset.mediaType === MediaLibrary.MediaType.video;
        valid.push({
          id: `restored-${asset.id}`,
          uri: asset.uri,
          localUri: asset.uri,
          name: asset.filename,
          type: isVideo ? 'video' : 'image',
          source: 'whatsapp',
          savedAt: Math.floor(asset.creationTime || Date.now()),
        });
        knownUris.add(asset.uri);
        knownNames.add(asset.filename);
        added = true;
      }
      
      if (!page.hasNextPage || !page.endCursor) break;
      after = page.endCursor;
    }
    
    return added ? valid : null;
  } catch (e: any) {
    // 🔧 CRITICAL: Handle permission errors gracefully
    if (e.message?.includes('Missing MEDIA_LIBRARY permissions')) {
      console.warn('[MediaLibrary] Permission denied for album rescan');
      // Optionally trigger permission request UI here
      return null;
    }
    console.log('[loadSavedItems] album rescan skipped:', e);
    return null;
  }
}
```
