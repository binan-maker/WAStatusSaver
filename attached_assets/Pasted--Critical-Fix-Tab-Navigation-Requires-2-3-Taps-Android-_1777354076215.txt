🎯 Final Architecture Note
Your tab navigation issue stems from three interconnected constraints:
🔴 Inline Handlers: onPress={() => fn()} creates new identity every render → breaks React.memo → dropped touches
🔴 Context Cascade: MediaContext state changes trigger parent re-renders → tab props change mid-touch → Android drops event
🔴 Main Thread Blocking: Heavy init tasks compete with navigation → JS thread blocked → delayed response
