Technical Reason: Android ties permissions to the app's UID (User ID). When you uninstall, the OS destroys the UID, wipes SharedPreferences/AsyncStorage, and revokes all granted permissions. A fresh install gets a new UID, so the app starts with zero permissions.

🎨 Question 2: Can We Style the SAF "Use This Folder" Button?
🚨 Short Answer: Directly styling the system button is IMPOSSIBLE.
🔍 Why (Android OS Restriction):
The SAF picker is a system component (com.android.documentsui), running in a separate process.
Android does not expose any API to customize, overlay, or inject UI into system dialogs.
This is intentional for security, cross-app consistency, and to prevent malicious apps from spoofing system prompts.
✅ Industry-Standard Workaround: Pre-Picker Guide Overlay
Instead of trying to modify the system picker, you show a clear, themed overlay BEFORE launching it that:
Shows exactly where the button is
Explains what to click
Uses your app's branding/colors
Automatically launches the picker when dismissed
